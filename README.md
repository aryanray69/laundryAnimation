# Laundry Services Landing Page

This is a beginner level website that is built for the educational and learning purpose. 

## Technologies Used

Here I have used , HTML 5, CSS and Google Fonts.

## HTML Structure

### Navigation Bar

Consists of Logo, Home , Services, About us, Contact us and Username

### Hero Section

Consists of Heading , Description Paragraph , Book a service button and Laundry Machine image.

## How to Run

1. Download the project.
2. Open the project folder.
3. Ensure the following files are present:
   - index.html
   - style.css
4. Open `index.html` in any web browser.
