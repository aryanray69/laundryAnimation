# Laundry Services Landing Page

A responsive Laundry Services Landing Page built using **HTML5** and **CSS3**. The webpage features a modern navigation bar, hero section, animated laundry image, call-to-action button, and responsive design for desktop, tablet, and mobile devices.

## Project Structure

```
Laundry-Services/
│
├── index.html
├── style.css
└── README.md
```

## Features

- Responsive Navigation Bar
- Modern Hero Section Layout
- Animated Laundry Machine Image
- Call-to-Action "Book a Service" Button
- Hover Effects on Navigation Links and Button
- CSS Variables for Easy Theme Management
- Mobile and Tablet Responsive Design
- Google Fonts Integration (Poppins & Roboto)
- Custom CSS Animation using Keyframes

1. Download or clone the project.

   - style.css
4. Open `index.html` in any web browser.
